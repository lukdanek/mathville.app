La machine à remonter le temps

Après les six époques, on construit dans le futur une machine à remonter le temps pour revenir à n’importe quelle époque.

Le jeu ne s’arrête pas après la dernière grande épreuve : on peut désormais construire une machine à remonter le temps dans le futur. Il suffit d’améliorer tous les bâtiments au plus haut niveau et de réussir cinq étapes, et la machine emmène votre enfant à n’importe quelle époque, en expédition, pour les souhaits des habitants et pour retenter l’épreuve. Chaque voyage dans le temps est un peu différent.

De temps en temps, les conseillers des époques passées appellent aussi à l’aide : réparer le village après une tempête, repousser un raid, éteindre un incendie ou retrouver un villageois perdu. Chaque appel, ce sont quelques calculs dans un autre décor : une partie terminée a encore de quoi offrir.
